# 農場主線（farm loop）

## Sub-features

- 開墾：面向田地（農場 x=4..9、y=3..5 的空地）按 `X`，體力 -2，HUD 記錄「開墾了一塊田」。
- 播種：用 `Z` 切到種子袋（預設第一個種子：月光豆），面向田地按 `X`，記錄「播下了 月光豆 種子」，體力 -1。
- 澆水：`Z` 切到水壺，面向作物按 `X`，記錄「澆了水」，體力 -1。
- 手動存檔：`S`，記錄「已存檔」，IndexedDB `saves` 的 `slot-1` 更新。
- 讀檔接續：重新整理後出現「已讀取存檔」，體力與日期保留。
- 睡覺：走到床位面向床並按 `X`，進入下一天、體力恢復到 100，記錄「你睡了一覺」。

## How to get to it (user POV)

新遊戲從農場出生點 (7,9) 開始。田地在出生點正北方，向上走四步到 (7,5)，面向 (7,4) 的田地。小屋在田地西側，床位在 (2,1)，工作台在 (4,1)，要繞過它。

## Driving it with Playwright

`scripts/verify.mjs farm-loop`。核心按鍵序列與 `tests/e2e/farm-loop.spec.ts` 相同：

1. `ArrowUp` × 4，`x`（開墾）。
2. `z`、`z`、`x`（播種）。
3. `z`、`z`、`x`（澆水）。
4. `s`（存檔），然後檢查 IndexedDB `slot-1`。
5. `page.reload()`，等待場景，檢查體力 `96 / 100` 與第 1 天。
6. `ArrowLeft` × 5，`ArrowUp`，`ArrowUp` × 3，`ArrowLeft` × 2，`ArrowUp`，`ArrowLeft`，`x`（睡覺）。
7. 檢查第 2 天、體力 `100 / 100`、金幣 `100 金`。
8. 再次重新整理，確認第 2 天保留。

## Gotchas

- 體力數字是精確的（`98 / 100`、`97 / 100`）。若規則數值改了（`content/tuning.json`），劇本的期望值也要跟著改，不要為了通過而放寬斷言。
- 種子預設是月光豆；若起始設定（`content/start.json`）改了持有的種子，`z z x` 播下的會是別的作物，「播下了 月光豆 種子」的斷言會失敗。
- 睡覺路徑依賴工作台與床的位置（`content/maps/house.json`）。改房子佈局時，步數要重算。
- 重新整理後要先等「已讀取存檔」與場景就緒，太早按鍵會被丟掉。
