# 晨露農場｜垂直切片 MVP 規格

工作標題：**晨露農場（Dewhollow Farm）**，為暫定名稱，可隨時更改。

## 目標

用一條完整、可存檔的遊玩循環，驗證下列假設：

1. 原創內容可以走完整個資料流程（資料 → 規則 → 畫面 → 存檔）。
2. 素材可以透過 manifest 替換，而不改動規則或測試。
3. 規則層（domain）不依賴 Phaser、DOM 或 IndexedDB，可用單元測試守護。

## 遊玩循環（驗收路徑）

出門 → 開墾 → 播種 → 澆水 → 睡覺 → 生長 → 收成 → 出貨 → 讀檔繼續

另含一個場景轉換（農場 ↔ 村莊）與一位 NPC 對話，以驗證轉場與旗標。

## 範圍內

| 項目 | MVP 內容 |
| --- | --- |
| 地圖 | 農場（含田地、房屋床鋪、出貨箱）、村莊（含 NPC、回農場的出口） |
| 時間 | 春季第 1 天起，每個動作耗 10 分鐘，睡覺至隔日 06:00 |
| 體力 | 上限 100，開墾 2、澆水 1、播種 1、收成 1；睡覺恢復全部 |
| 工具 | 鋤頭（開墾）、水壺（澆水）、種子袋（播種） |
| 作物 | 6 種原創作物，生長天數依序 1、2、3、5、8、13 天；澆水的田地每晚生長 1 天；收穫隨機產出 1 到 5 個 |
| 經濟 | 出貨箱放入作物，隔日睡醒時結算售價；售價 = 種子價 × 3 × (1 + 0.1 × 成長天數)，四捨五入 |
| NPC | 1 位（毛毛，村莊），首次對話贈送種子，之後只顯示一句話 |
| 存檔 | 單一存檔槽，睡覺時自動存檔，按 S 手動存檔，載入後接續 |
| 素材 | 全部為程式產生的占位圖，透過 `content/assets.json` 登錄，可替換 |
| 方向與動作 | 主角四方向（上、下、左、右）各有一張圖，轉身時只換圖；移動時有上下起伏與腳步塵土；開墾、澆水、播種、收成、出貨、睡覺各有效果（塵土、水滴、新芽、閃光飄字、淡出淡入） |

## 範圍外（明確不做）

- 季節切換、跨年、天氣、節慶
- 畜牧、礦坑、釣魚、採集、料理
- 戀愛、婚姻、家庭
- 滑鼠操作與手把（規格保留，MVP 不實作）
- 音效與音樂（之後以原創素材補上）
- 匯入、匯出存檔（列為下一階段）
- PWA 離線安裝

## 操作

| 按鍵 | 功能 |
| --- | --- |
| 方向鍵 | 移動（一次一格），面向最後移動的方向 |
| X | 互動：對面前的田地、房屋床鋪、出貨箱、NPC 或作物執行動作 |
| Z | 切換工具：鋤頭 → 水壺 → 種子袋 |
| C | 種子袋時切換要播的種子 |
| S | 手動存檔 |

收成不需要工具，面前有成熟作物時按 X 即可。

## 核心規則

- 田地狀態：`grass` 不可開墾；`field` 可開墾；開墾後變為 `soil`。
- 作物只能種在 `soil`，每格最多一株。
- 澆水只影響當日：睡覺結算時，已澆水的作物生長 1 天，然後清除所有澆水標記。
- 作物 `growthDays >= days` 即為可收成。
- 缺水：作物當晚未澆水，第 1 晚成長天數減 1（最低為 0），連續第 2 晚未澆水則枯死並清除。澆水後缺水計數歸零。
- 收穫：每次收穫隨機產出 1 到 5 個（均勻分布），隨機狀態存於存檔，讀檔後結果一致。
- 出貨箱只接受作物；結算售價 = 單價 × 數量。
- 體力不足時動作失敗，並提示「體力不足，請回家睡覺」，不消耗時間。
- 動作失敗不改變狀態，也不耗時間。

## 驗收條件（MVP Done）

1. `npm test` 全部通過，domain 與 application 規則有測試先行的紀錄。
2. `npm run typecheck` 與 `npm run build` 通過。
3. 手動或 E2E 可完成：開墾 → 播種 → 澆水 → 睡覺 → 收成 → 出貨 → 隔日收到金錢。
4. 重新整理後，存檔可讀回田地、金錢、時間與旗標。
5. 把 `content/assets.json` 的某個占位圖改成真實檔案，遊戲仍可運行，且測試通過。
6. 存檔格式錯誤或 IndexedDB 不可用時，畫面顯示真實錯誤，不靜默失敗。

## 已知限制（MVP 接受）

- 數值（售價、生長天數、體力成本）為初版假設，需要試玩後調整。
- 占位圖只用來驗證流程，正式美術需另行製作。
- 目前只有鍵盤操作，且尚未在行動裝置上驗證。
