# 美術風格指引

## 目標風格

採用 **32-bit 全彩像素美術**：Q 版比例、清晰的大色塊輪廓、細緻但可辨識的像素群、豐富的全彩陰影與高光。整體明亮飽和，以藍綠為主、粉色點綴，輪廓使用深棕而非純黑。

「32-bit」在本專案指 RGBA8888 圖片格式（紅、綠、藍、透明度各 8 bit），不是特定主機的像素格式限制。維持像素邊緣銳利，不加模糊、掃描線或整張馬賽克濾鏡。

## 角色一致性

- 小涵是女性玩家角色；長直深棕髮、齊瀏海與淺棕髮尾，棕色大眼、淺膚色，穿棕色外套、黑裙、白鞋，配深色斜背包並持銀白平板。
- 毛毛是男性 NPC；蓬鬆深棕近黑捲髮、深棕大眼、淺膚色，穿深海軍藍針織上衣、灰橄欖色工裝褲與白鞋。
- 兩人使用相同頭身比例、線條粗細、像素密度與打光；髮型、衣服、配件和識別色需能穩定辨認。角色生成以 `docs/CHARACTERS.md` 為準。

## 尺寸與圖層

| 類別 | 規格 |
| --- | --- |
| 遊戲格 | 64 × 64 px |
| 地形與物件母版 | 128 × 128 px（2×；遊戲縮至 64 px） |
| 角色母版 | 依既有 rig 畫格，2× 輸出；角色比例與腳底錨點沿用 `content/rigs.json` |
| 地面 | 不透明 RGBA PNG；草地、水、農地、道路、室內地板等可單獨鋪格，地形接縫需無縫 |
| 物件 | 真透明 alpha PNG；樹木、岩石、家具、門、工具等與地面分開，逐層繪製 |
| 輪廓 | 深棕像素線；在實際顯示尺寸維持完整，不殘留去背色邊 |

每格先畫地面，再畫透明物件；角色、作物和互動特效按深度置於物件層上方。物件格沒有明確底層資料時，渲染器以最近的地面格推定底層。

## 原創與權利界線

- 角色、地名、作物與文字皆為原創，遵守 [ORIGINALITY.md](ORIGINALITY.md)。
- 參考附件只提供通用的 Q 版比例、色彩飽和度與像素質感；不得複製既有遊戲角色外觀、標誌、介面、文字或畫面構圖。
- 每個新素材都要在 `content/assets.json` 登錄正確的用途、檔案及來源。

## 品質檢查

- 小涵與毛毛的臉型、髮型、衣著、配件和身形需在多方向素材中保持一致。
- 地面放大時仍有清楚像素群；相鄰鋪設時沒有可見接縫。
- 物件 alpha 外部為透明，邊緣無綠幕或黑邊；疊在草地、水、農地、道路和室內地板上都能辨認。
- 遊戲以 1×、2×、4× 檢視時，輪廓、五官、手持物與腳底定位都可辨識。
