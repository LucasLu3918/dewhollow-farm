# 角色美術風格指引（草案）

## 目標風格

參考使用者提供的方向：明亮飽和的像素風 Q 版角色、大頭小身、清楚的深色輪廓線、柔和的高光與陰影、以藍綠與粉色為主要點綴。

這是風格方向，不是要重現任何既有作品。

## 權利界線

- 不使用、不描摹、不改編任何既有遊戲的角色、標誌、UI 元件或畫面。
- 參考圖中的既有遊戲標誌、介面與特定角色（包含其名稱與外觀）不得進入本專案的素材。
- 角色必須是原創設計，並在 `content/assets.json` 登錄 `source`（例如「本機模型生成後人工修整」）。

## 技術規格（建議，待確認）

| 項目 | 建議 |
| --- | --- |
| 地圖格子 | 64 × 64 px（D2 已決定：路線 B 手繪卡通；程式已於 M0 改為 64 px） |
| 主角與 NPC | 角色框 64 × 80 px，允許上半身略超出格子 |
| 方向 | 上、下、左、右各一組；左右可水平翻轉共用 |
| 動畫 | 站立 1 幀、行走 2 幀；MVP 可先只做站立 |
| 調色 | 每個角色不超過 16 色，共用一組 8 色的基礎膚色與陰影色 |
| 輪廓 | 2 px 深棕外框，不使用半透明描邊 |
| 輸出 | PNG（透明背景），以 sprite sheet 或單張檔案提供 |

## 製作流程（建議）

1. 以文字描述角色設定（外型、配色、性格）。不附既有遊戲的參考圖；使用者自有角色的原型圖僅作私人參考，處理方式見 [ART_PIPELINE.md](ART_PIPELINE.md)。
2. 用本機影像模型產生草稿，固定尺寸與風格提示詞。
3. 人工縮放到目標像素、統一調色盤、修正輪廓與方向。
4. 放入 `public/assets/characters/`，在 `content/assets.json` 指定 `file`。
5. 跑 `npm run check` 與 `npm run test:e2e`，確認替換後流程不變。
