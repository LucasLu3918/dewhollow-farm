# 上線路線圖（Roadmap）

目標：把垂直切片 MVP 推進到**可公開上線**的完整遊戲，首次遊玩至少 2 小時、之後可永久經營。

本文件是總綱；細節分見：

| 文件 | 內容 |
| --- | --- |
| [GAME_DESIGN.md](GAME_DESIGN.md) | 系統設計、黏著度結構、經濟與遊玩時數預算 |
| [CONTENT_PLAN.md](CONTENT_PLAN.md) | 居民、任務、事件、節慶、成就的內容清單 |
| [ART_PIPELINE.md](ART_PIPELINE.md) | 美術風格鎖定、素材清單、本機產圖與後製流程 |

| [DECISIONS.md](DECISIONS.md) | 待使用者決定的事項（每項至少兩個選項，含推薦） |

既有文件：[MVP_SPEC.md](MVP_SPEC.md)（v0.1 基準，其「範圍外」項目由本路線圖接手）、[ORIGINALITY.md](ORIGINALITY.md)（所有新內容都受其約束）、[CHARACTERS.md](CHARACTERS.md)、[ART_STYLE.md](ART_STYLE.md)、[TUNING.md](TUNING.md)。

## 現況（2026-10-21 盤點）

- 技術：Phaser 4.2.1、TypeScript、Vite、Dexie（IndexedDB）、zod、Vitest、Playwright；約 3,300 行含測試。
- 分層乾淨：domain 純規則、application 指令、infrastructure 實作、presentation 呈現。
- 內容：2 張 16×12 單螢幕地圖、6 種作物、1 位 NPC、1 個存檔槽、存檔 schema v1。
- 美術：全部為程式產生的占位圖（`content/assets.json` 皆標「占位」），沒有 `public/`。
- 缺口：沒有 git commit、沒有 CI、沒有音訊、沒有鏡頭捲動、沒有季節／天氣／任務／事件／成就、僅鍵盤操作。

## 2 小時時數預算（摘要，詳見 GAME_DESIGN）

- 1 季 = 20 天、1 年 = 80 天；目標每遊戲日約 3 分鐘真實時間。
- 第一年春＋夏（40 天）≈ 2 小時，是「至少兩小時」的保底內容；秋＋冬補到約 4 小時；第 2 年起進入無盡循環。
- 以上是設計假設，**必須用模擬機器人與真人試玩校準**（TECH_PLAN「遊玩時數模擬」）。

## 風險與對策

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| 本機 AI 模型不產生真正的像素圖，也沒有透明背景，連續動畫幀不一致 | 風格不統一、動畫抖動 | 單一主體單張產圖、同提示詞模板與固定 seed；後製統一調色盤與輪廓；行走動畫以程式變形為主（見 ART_PIPELINE） |
| 圖生圖編輯模型在本機很慢（Qwen Edit 實測每步 316–450 秒）或授權為「other」 | 以參考圖轉繪不可行或有授權疑慮 | 預設改為「看圖寫角色描述後文生圖」；編輯模型僅作小規模試驗，需使用者同意授權 |
| 素材量大（約 250 件），一次只能跑一個 MLX 任務 | 產圖耗時，約 7–8 小時 GPU | 分批、背景執行、先做最小可玩素材集再擴充 |
| 內容量大、數值難平衡 | 前期太快或太慢 | 全部數值進 JSON；加模擬測試；每里程碑結束做一次校準 |
| 版權：以牧場物語為「原型」 | 侵權風險 | 只借鏡通用玩法類型；名稱、文字、美術、數值全部原創；ROM 僅限私人觀察，見 ORIGINALITY.md |
| 角色原型圖取自真人風格插畫 | 公開發布涉及肖像意願 | 遊戲內為 Q 版重新設計，不保留寫實面貌；發布前請使用者確認 |
| 範圍過大 | 永遠做不完 | 里程碑可獨立上線；M4、M5 的項目逐項標優先級（P0 必做／P1 應做／P2 可延後） |
