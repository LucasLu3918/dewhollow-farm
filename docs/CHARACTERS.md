# 角色源設定：毛毛與小涵（草案）

本文件是兩位角色的源設定，由使用者提供、自有權利的原創角色。以下只描述外觀特徵，之後繪製素材時依此文字重新設計，不使用任何既有遊戲的截圖或角色素材。

## 權利與來源

- 毛毛、小涵及其寵物為使用者自有權利的角色。（原設定名稱為玖峯與雅涵，已由使用者改名。）
- 參考圖的畫面來自既有網路遊戲的截圖，其中的標誌、介面、職業名稱、公會與聯盟名稱、遊戲內對話，**都不屬於本專案**，不得放入遊戲。
- 美術一律重新繪製，不得從截圖擷取或描摹畫面中的角色像素。
