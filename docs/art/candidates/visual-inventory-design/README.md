狀態：**候選，尚未經使用者核准，禁止整合至正式遊戲**。日期：2026-10-26。

開啟 [`index.html`](index.html) 檢視兩個方向的完整靜態板：農場／村莊概念場景、桌機背包與選中道具詳情、390×844 直式，以及 844×390 橫式。

## 兩個方向

- **A｜保守高精修（推薦）**：降低草地對比與重複感，明確處理地塊及道路邊緣；維持清楚、低干擾的層次。背包使用較薄的深棕框與稻草色底，保持列表優先。
- **B｜層次更強／細節更密**：增加近景樹木、圍籬、石砌高差與建物簷影；背包使用厚框和內亮邊，強化詳情區。美術工作量較高，手機上也更有覆蓋感。

兩方向共用相同欄位、容量、選中物品及手機視窗尺寸，以便比較介面差異。像素細節圖示是手繪 SVG 線框概念，非已核准素材。
