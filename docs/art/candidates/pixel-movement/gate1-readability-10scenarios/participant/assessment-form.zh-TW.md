## 評分規則

- 評分者在所有觀察者完成前保管 `answer-key.json`，依報告列出的目標類別與接受答案逐圖計 0 或 1 分。
- 每位觀察者至少答對 9／10 才達到附件 §11.1 的 90% 門檻。至少邀請 3 位互不討論的觀察者；分別記錄每人分數與總體正確率。
- 空白、同時選擇互斥答案或無法辨識均計 0 分。不得事後調整答案鍵以提高分數。
- 本表為人工評分模板。尚未填入觀察者答案，也不代表可讀性測試已通過。
