# Dewhollow Farm｜世界美術指引 v2 草稿

> **狀態：提案，待使用者審核。** 使用者先前已選定 pixel32／16-bit 時代風格方向作為候選工作的起點；這不等於核准本草稿、整體場景或任何確切素材版本。正式預設仍為 `legacy`；`pixel32`、`pixel16` 為 QA-only。此草稿不切換正式素材，也不撤銷既有核准。

本稿依世界重製計畫整理，供場景與素材候選製作和審核。現行 [美術風格指引](../../ART_STYLE.md) 與其核准的 Golden Reference 繼續適用於既有正式素材；如本提案與舊規格不同，須以新樣張和使用者決定處理，不改寫舊核准歷史。像素尺寸 `32px` 不等於舊指引中的 RGBA8888「32-bit」色彩格式。

## 視覺目標

「晨光森林農莊」：溫暖、清楚且有人生活的原創農村世界。戶外、室內、人物和介面應共享材質與光線語言；農場及初始小屋先完成同風格垂直切片，再擴展地圖。保留角色既有可辨識特徵與原創設定，依 [角色設定](../../CHARACTERS.md) 及 [原創規範](../../ORIGINALITY.md) 執行；不得複製其他作品的素材、角色、地圖或介面。

## 像素、投影與畫面層次

| 項目 | 候選目標／檢查方式 |
|---|---|
| 投影 | 正交俯視偏 3/4；地面、建築正面與家具在同場景遵守同一視角。 |
| 地表 | 原生 32×32 px／格；邏輯世界維持 64 單位／格，候選以 2× 最近鄰顯示。實際顯示縮放與 viewport 仍須測試。 |
| 玩家 | 基準 32×48 px，四方向維持身份、身形與腳點；候選圖集錨點以其 manifest 為準，目前 player `(16,47)`。特殊配件可另訂尺寸。 |
| 寵物與 NPC | 保持同一像素密度，貓與矮袋鼠須清楚辨認為動物；各方向及每個新版本獨立審核。 |
| 構圖 | 地表與接縫 → 建築／地物底座 → 依腳底 Y 排序的角色與物件 → 屋簷／樹冠前景 → 光效／天氣 → DOM UI。碰撞與遊戲規則不由美術層決定。 |
| 光線與輪廓 | 主光由左上方照入、暖光冷影；輪廓使用深棕，關鍵物件約一個原生像素線，避免大面積純黑粗框。 |
| 材質 | 大色塊與成簇像素；地面可平鋪，草／泥／路使用一致過渡；物件有可信的接地陰影。 |
| 檔案與錨點 | PNG RGBA，透明用途須真透明；整數座標、最近鄰、無模糊與去背殘影。每筆保存尺寸、來源、SHA、pivot／foot anchor、碰撞腳印與審核狀態。候選格式見 [pixel32 規格](../candidates/pixel-movement/gate1-assets/DF-ART-02-PIXEL32-SPEC.zh-TW.md)。 |

## 場景與農務

農場配置要有清楚住宅、路徑、出貨箱與可達耕作區；小屋須具牆面、地板、床、料理台、工作台、收納及可通行入口，避免空曠單色場外。素材先在完整場景中確認比例、接地、遮擋與動線，再拆成可拼接的 tile 和獨立物件；不得將整張 AI 示意圖直接切作正式 atlas。

農地視覺要能區分未開墾、乾土、濕土、播種、發芽、成長與成熟；1×1、3×3 和 L 型需檢查接縫。角色四方向行走應維持腳點與輪廓，不依賴過度跳動或拉伸。這些是候選目標，尚須遊戲內與手機實測；現有 domain、存檔及經濟規則不因美術草稿改變。

## 現有 A/B 參考與限制

- [pixel16 農場畫面](../candidates/pixel-movement/gate1-mapscene-pixel16-pixel32-scene-comparison/screenshots/pixel16-game.png)／[pixel32 農場畫面](../candidates/pixel-movement/gate1-mapscene-pixel16-pixel32-scene-comparison/screenshots/pixel32-game.png)：既有紀錄使用同一隔離 v13 farm 資料、1280×900 viewport、DPR 1，遊戲區各 824×617；詳見 [比較報告與量測](../candidates/pixel-movement/gate1-mapscene-pixel16-pixel32-scene-comparison.zh-TW.md)。
- 兩者**覆蓋不同**：pixel16 使用 16px atlas 和三階作物，角色沿用舊素材；pixel32 使用專用地圖、玩家動畫與房屋／樹冠圖層，作物等仍使用舊素材。差異不能全部歸因於像素尺寸，也不構成完整風格 A/B 或 Gate 通過。
- [固定 12×10 預覽](../candidates/pixel-movement/gate1-preview/evidence.zh-TW.md)使用相同合成配置，適合討論地表色彩與局部輪廓；它不是遊戲內資料。8bit 和 16bit 是時代風格名稱，對應地表原生 16px 和 32px，與 PNG 色深無關。
- [概念圖](../candidates/pixel-movement/README.zh-TW.md)由 Image Generation 產生，為靜態討論稿，並非可直接投入遊戲的正式素材。既有素材和候選的狀態不因截圖或此草稿改變。

## 待審核與交付順序

1. 提出農場與小屋整場景樣張，呈現地表、家具、人物、田地狀態及一致的光線與尺度。比較圖應盡量控制同場景、同存檔、viewport、顯示尺寸與素材覆蓋，並明列差異。
2. 使用者審核方向、色票、角色與動物辨識、場景比例及手機可讀性；若需比較 16px 替代方向，補齊等價內容與實測，不以局部混搭圖推論結論。
3. 按 [素材審核流程](../asset-review.md) 對每個確切候選、來源與 SHA 取得明確核准；經既有 gate 整合並保留 provenance，才可進入正式素材清單。風格選擇或自動檢查均不能替代逐檔核准。
4. 以真實 Phaser 截圖、地表接縫、遮擋、四方向走路與農務操作證據驗證垂直切片；桌面、手機直橫向及實機限制逐項記錄。未執行者標記未驗收。
