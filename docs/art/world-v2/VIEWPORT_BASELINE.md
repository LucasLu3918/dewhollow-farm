# DF-V2-002｜視窗尺寸故障觀測基線

本紀錄整理一次既有的隔離瀏覽器量測，不代表完整重現矩陣、根因已證實或問題已修復。量測資料在本文件撰寫前產生；資料未附擷取時間或被測版本指紋，因此不能證明它對應目前 HEAD 的確切檔案內容。盤點時 HEAD 為 `3b456898367d79de8f4eb496b6fd733931a29f88`，但不能把此 SHA 當作量測版本的證明。

## 方法及範圍

原始腳本建立新的 headless Chromium browser/page，使用 1280×720 viewport、DPR 1，透過本機開發伺服器載入遊戲。腳本沒有指定持久瀏覽器設定檔；逐步移動進屋，記錄存檔、開關存檔面板、重載、嘗試睡覺及變更 viewport。每個快照等待 500ms 後讀取 DOM 矩形、canvas buffer、DEV camera／viewport／layout 與 DPR。原始 JSONL 只含畫面尺寸、場景及輸入裝置能力資訊，未見帳號、存檔內容或憑證；本頁僅保存所需的數值摘要，不保存原始暫存檔或本機絕對路徑。

- 原始量測 JSONL SHA-256：`73d8f2d71f93109f47c672370705a3f2810942c463dc028dd21cf9f528d11a4f`。
- 原始量測腳本 SHA-256：`1dbd9f559326c56e4774a2a6652b299b068349b9c76b70a9e2e6e9d236150008`。
- 以原腳本觀察為準：`sleep` 是按鍵後的快照標籤；現存記錄未包含睡眠成功的獨立斷言，不能宣稱成功睡覺。

## 可核實數值

寬高單位為 CSS px；buffer 為 canvas 像素。小數四捨五入至兩位；`zoom` 為 camera 值，不是 CSS scale。最後兩列改變了 viewport，不能與固定視窗下的操作直接比較。

原始腳本另有一項控制實驗：比較一般面板及以臨時 CSS 固定高度的面板。其原始 stdout 沒有保存，因此本文件不將任何控制組差異或因果結論列為已驗證。完整事件時序、兩動畫影格快照、面板確認、互動物件、100 次循環、所有裝置／DPR 與實機均未由此資料證明。
