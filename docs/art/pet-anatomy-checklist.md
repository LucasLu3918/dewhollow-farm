## 物種目視檢查表

每次審核新圖時，先記錄 asset key、候選檔 SHA-256、方向、動作／畫格、實際遊戲顯示尺寸及可查看的預覽。逐項檢查後，仍須由使用者核准該確切候選版本；CI、AI 或既有素材核准不能代替目視核准。

### 黑貓（`cat`）

規格依據：[角色寵物 brief](character-briefs.md#寵物物種修復2026-10-23)。以下均為候選檢查項目，**尚未逐項簽核**：

- [ ] 可辨認為黑色家貓，身體自然四足著地。
- [ ] 可見貓科耳朵、短口鼻與鬍鬚等物種特徵。
- [ ] 尾巴形狀和比例符合當次書面 brief；若有差異，記錄差異並交由人工判斷。
- [ ] 沒有直立人形軀幹、人手／手指、衣物或人獸混合特徵。
- [ ] 在候選所屬方向、動畫幀、透明背景及實際顯示尺寸下輪廓清楚；只簽核已檢視的範圍。

### 矮袋鼠（`marsupial`／quokka）

規格依據：[角色寵物 brief](character-briefs.md#矮袋鼠quokka)。以下均為候選檢查項目，**尚未逐項簽核**；已核准的 48×48 村莊畫面不會替這些項目打勾：

- [ ] 可辨認為 quokka，具棕灰色短毛、短而寬的口鼻及小圓耳。
- [ ] 身體緊實低伏、自然四足；後肢比例與短前肢符合物種輪廓。
- [ ] 自然矮袋鼠尾巴可辨識，沒有不自然的肢體或尾巴變形。
- [ ] 沒有小熊式輪廓、人形直立軀幹、人手／手指、衣物或人獸混合特徵。
- [ ] 在候選所屬方向、動畫幀、透明背景及實際顯示尺寸下輪廓清楚；只簽核已檢視的範圍。

## 每次人工簽核紀錄

每個確切候選版本各自記錄：

| 欄位 | 紀錄 |
|---|---|
| Asset key | 待填 |
| 候選檔 SHA-256 | 待填 |
| 方向、動作／畫格、遊戲顯示尺寸 | 待填 |
| 預覽路徑或可查看連結 | 待填 |
| 檢查項目結果／例外 | 待填 |
| 使用者決定（`approved`／`rejected`） | 待填 |
| 核准者與日期（ISO `YYYY-MM-DD`） | 待填 |

可將這筆人工決定整理成閘門接受的 JSON 核准紀錄；詳見 [`tools/art/asset_review_gate.py`](../../tools/art/asset_review_gate.py)。沒有針對 asset key 和候選 SHA-256 的 `approved` 紀錄時，素材不得經該閘門輸出。
